Oblivion 0.2.4 — Windows friends beta

This first updater-enabled beta prepares Oblivion to receive future signed launcher updates from its GitHub Pages host. It retains the existing launcher, Fabric companion, approved cosmetics and HUD features, with the same application identity and data locations.

Future updates can be reviewed in the launcher with version information and release notes. The updater requires a valid publisher signature bound to the announced version.

The initial update feed remains inactive until a newer approved release is ready. A genuine automatic download/install/restart has not yet passed. Clean-install and interrupted-upgrade acceptance scenarios remain unverified.

The Windows installer and detached updater signature have been built and verified locally. Publication remains subject to owner approval. The installer has not been installed during this verification.
